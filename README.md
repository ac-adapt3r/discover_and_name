# Discover and Name
This small mod labels every item "Unknown Node" or "Unknown Item" and lets players name the items permamently whatever they want.
## How to use
To name an unnamed item, you need to have the `interact` privilege, (usually, everyone has it by default) wield the item you want to name, and use the command:
```
/name_item <name>
```
To remove an item name, you need to have the `remove_item_name` privilege, wield the item of which name you want to remove, and use command:
```
/remove_item_name
```
## Are item names shared or private?
The item names are shared, which means everyone on a server will have same item names.
## Compatibility
This mod is compatible with pretty much any game or mod
